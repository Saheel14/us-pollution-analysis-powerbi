# US Pollution Analysis (Power BI Project)

This Power BI dashboard presents a detailed analysis of air pollution data across different states in the United States. It helps identify trends, high-risk areas, and pollutant types over time.

## 📊 Dashboard Highlights:
- Pollution levels by state, year, and pollutant type
- Comparison of PM2.5, Ozone, and CO trends
- Average Air Quality Index over time
- Interactive filters for deeper insights

## 🛠 Tools & Skills Used:
- Power BI
- DAX
- Data Cleaning and Modeling
- Custom Visuals and Storytelling
